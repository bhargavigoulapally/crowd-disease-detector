# 🌱 Crop Disease Detector

An AI-powered **Crop Disease Detection System** that analyzes crop leaf images and predicts possible plant diseases using an image-classification model.

The application is built with **Python and Streamlit** and provides an easy-to-use web interface where users can upload a crop leaf image and receive an AI-based prediction with a confidence score.

## 📌 Features

* 🌿 Upload crop leaf images
* 🤖 AI-based disease detection
* 📊 Confidence score for predictions
* 🦠 Disease identification
* 📋 Disease description
* 🛡️ General prevention and management information
* 📈 Top AI predictions
* 🖥️ Interactive Streamlit interface
* ☁️ Easy deployment using Streamlit Community Cloud
